# Как установить CardioAI

Программа пока не подписана сертификатом разработчика. Поэтому macOS и Windows при первом запуске предупреждают о неизвестном разработчике. Ниже — как открыть её один раз; дальше она запускается обычно.

## Где скачать

1. Откройте страницу проекта на GitHub → **Releases** → последняя версия.
2. Внизу, в разделе **Assets**, скачайте файл для своего устройства. Входить в GitHub не нужно.

| Устройство | Файл |
| --- | --- |
| Windows 10/11 (64 бит) | `CardioAI-Windows.zip` |
| Mac на M1, M2, M3, M4 | `CardioAI-macOS-AppleSilicon.zip` |
| Android | `CardioAI-Android.apk` |

Mac на процессоре Intel пока не поддерживается.

## Mac

1. Распакуйте zip и перенесите **CardioAI** в «Программы».
2. Запустите. Появится окно «Не удалось проверить разработчика» — нажмите **Готово**.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**.
4. Внизу, у строки про CardioAI, нажмите **Всё равно открыть** и подтвердите паролем.

## Windows

1. Распакуйте zip в удобную папку, например `Документы\CardioAI`.
2. Запустите `CardioAI.exe`.
3. Если появится синее окно «Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**.
4. Если антивирус удалил файл, добавьте папку программы в исключения. Это частая ложная тревога на программы, собранные PyInstaller.

## Android

1. Скачайте `CardioAI-Android.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника.

## Первый запуск на компьютере

1. **Пациенты** работают сразу. Несколько файлов с прибора можно добавить разом: «Пациенты» → «Импорт ЭКГ с прибора». Программа сама разложит их по пациентам по имени, введённому на кардиографе.
2. Нейросети: **Анализ ИИ** → отметьте нужные → **Установить выбранные**. Python и библиотеки — около 2,5 ГБ; веса: DeepECG SL — 7 МБ, DeepECG SSL — 2,2 ГБ, ECGFounder — 0,4 ГБ. Программа показывает, сколько места нужно. Если связь оборвалась — нажмите кнопку ещё раз, загрузка продолжится. Веса, уже лежащие в `~/CardioAI/work`, повторно не скачиваются.
3. Печать: на странице ЭКГ или сравнения — **Печать**. Получается лист A4: измерения, ЭКГ на миллиметровой сетке и место для заключения врача. Печатайте в масштабе 100 % (импульс на сетке = 10 мм).
4. Папка обмена: **Данные → Папка обмена → Включить**. По умолчанию это папка «CardioAI Обмен» в домашней папке (на Windows — в «Документах»).

## Где лежат данные

| | Mac | Windows |
| --- | --- | --- |
| Пациенты и ЭКГ | `~/Library/Application Support/CardioAI` | `%APPDATA%\CardioAI` |
| Нейросети | `~/Library/Application Support/CardioAI/work` | `%LOCALAPPDATA%\CardioAI\work` |

Резервная копия: **Данные → Скачать резервную копию**.

CardioAI — исследовательская программа. Результаты — технические оценки, а не диагноз.
